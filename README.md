# Проверка скорости скачивания

Скрипт `download_speed.py` последовательно скачивает указанный URL 10 раз, каждый раз читает ответ целиком и выводит время и размер каждого ответа. В конце он показывает среднее время одного запроса, общий объём данных и среднюю скорость передачи.

## Запуск

Нужен Python 3. Запускать можно из этой папки:

```bash
python download_speed.py https://example.com/image.jpg
```

В Windows также подойдёт:

```powershell
py .\download_speed.py https://example.com/image.jpg
```

Скорость считается по сумме байтов всех десяти ответов и суммарному времени скачивания; единицы — **Мбит/с** (десятичные мегабиты: 1 Мбит = 1 000 000 бит). Время на паузу между запросами в расчёт не входит. Для каждого запроса установлен тайм-аут 60 секунд.
